# 👜 SackBag - Online Bag Shopping Web Application

SackBag is a full-stack e-commerce web application for shopping bags online. The application allows users to browse products, create accounts, log in securely, add products to their cart, and view cart details with price calculations.

The project focuses on implementing backend functionality using Node.js, Express.js, MongoDB, and server-side rendering with EJS.

---

## 🚀 Features

### 👤 User Features

- User registration and login system
- Secure password hashing using bcrypt
- JWT-based authentication
- User session management
- Browse available products
- Add products to cart
- View cart items
- Automatic price calculation
- Flash messages for user feedback

### 🛍️ Product Features

- Product listing page
- Product image upload and storage
- Dynamic product cards
- Product details:
  - Name
  - Price
  - Discount
  - Colors
  - Images

### 🛒 Cart Features

- Add products to cart
- View all added products
- Calculate:
  - Subtotal
  - Platform fee
  - Final amount
- Remove products from cart
